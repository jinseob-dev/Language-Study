# **Understanding Environment Variables**

Environment variables are special values that your Linux system uses to store information about your computing environment. Think of them as labeled containers that hold data your programs and shell need to function properly. 
These variables tell your system where to find programs, what your username is, which directory you're currently in, and many other important details. Every time you open a terminal or run a program, it can access these variables to understand how it should behave.  
Environment variables have names written in UPPERCASE letters, like <mark>HOME</mark>, <mark>USER</mark>, or <mark>PATH</mark>. Each variable contains a value - for example, <mark>HOME</mark> might contain <mark>/home/alice</mark> if your username is alice.  
Programs use these variables to make decisions. When you type a command like <mark>ls</mark>, your system checks the <mark>PATH</mark> variable to know where to look for the <mark>ls</mark> program. When a program needs to know your username, it reads the <mark>USER</mark> variable.
The beauty of environment variables is that they provide a standard way for all programs to access the same information. Instead of each program figuring out your home directory separately, they all just read the <mark>HOME</mark> variable.  
Your shell creates many environment variables automatically when you log in, but you can also create your own or modify existing ones to customise how your system works.   


## **Viewing and Setting Variables**

To see what environment variables exist on your system, use the <mark>printenv</mark> command:  
`printenv`
This shows all environment variables and their values. To see a specific variable, add its name:  
`printenv HOME`
`printenv USER`
You can also use the <mark>echo</mark> command with a dollar sign before the variable name:  
`echo $HOME`
`echo $USER`
`echo $PATH`
The dollar sign tells the shell to substitute the variable's value instead of printing the literal text.  
To create or change a variable for your current session, use the assignment operator:
`MY_VARIABLE="hello world"`
'EDITOR="nano"'
Remember there are no spaces around the equals sign. After setting a variable this way, you can use it in the same terminal session:
`echo $MY_VARIABLE`
However, variables created this way are only available in your current shell session. They disappear when you close the terminal. 
You can also see all variables (including local shell variables) using the <mark>set</mark> command, though this produces much more output than <mark>printenv</mark>.


# **Persistent Environment Variables**

Variables you set directly in the terminal only last for that session. To make environment variables permanent, you need to add them to configuration files that run automatically when you start your shell.  
For variables that affect only your account, edit the <mark>.bashrc</mark> file in your home directory: 
`nano ~./bashrc`
Add your variable assignments at the end of the file:
`export MY_VARIABLE="permanent value"`
`export EDITOR="nano"`
The <mark>./bashrc</mark> file runs every time you open a new terminal window. After saving the file, either restart your terminal or reload the configuration:
`source ~./bachrc`
For variables you want available to all programs (not just terminal sessions), use <mark>.profile</mark> instead:
`nano ~./profile`
Add the same export statements. The <mark>.profile</mark> file runs when you log into your user account.   
If you want to set variables for all users on the system, you can edit system-wide files like <mark>/etc/environment</mark> or <mark>/etc/profile</mark>, but this requires administrator privileges:
`sudo nano /etc/environment`
In <mark>/etc/environment</mark>, writhe variables without the <mark>export</mark> command:  
`MY_SYSTEM_VAR="system wide value"`
Changes to these files take effect after you log out and log back in.
