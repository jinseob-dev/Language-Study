# **2.1 Variables**

A **variables** is a name that refers to a value. To create a variable, we can write a **assignment statement** like this.
`n = 17`
An assignment statement has three parts: the name of the variable on the left, the equals operator, <mark>=</mark>, and an expression on the right. In this example, the expression is an integer. In the following example, the expression is a floating-point number.
`pi = 3.141592653589793`
And in the following example, the expression is a string.
`message = 'And now for something completely different`
When you run an assignment statement, there is no output. Python creates the variable and gives it a value, but the assignment statement has no visible effect. However, after creating a variable, you can use it as an expression. So we can display the value of <mark>message</mark> like this:
`message`
`'And now for something completely different'`
You can also use a variable as part of an expression with arithmetic operators.
`n + 25`
`42`
`2 * pi`
`6.283185307179586`
And you can use a variable when you call a function.
`round(pi)`
`3`
`len(message)`
`42`

# **2.3 Variable names**

Variable names can be as long as you like. They can contain both letters and numbers, but they can't begin with a number. It is legal to use uppercase letters, but it is conventional to use only lower case for variable names.
The only punctuation that can appear in a variable name is the underscore character, <mark>_</mark>. It is often used in names with multiple words, such as <mark>your_name</mark> or <mark>airspeed_of_ubladen_swallow</mark>.
If you give a variable an illegal name, you get a syntax error. The name <mark>million!</mark> is illegal because it contains punctuation.
`million! = 1000000`
  Cell In[12], line 1
    million! = 1000000
           ^
SyntaxError: invalid syntax
<mark>76trombones</mark> is illegal because it starts with a number.
`76trombones = 'big parade'`
  Cell In[13], line 1
    76trombones = 'big parade'
           ^
SyntaxError: invalid syntax
<mark>class</mark> is also illegal, but it might not be obvious why.
`class = 'Self-Defence Against Fresh Fruit'`
  Cell In[14], line 1
    class = 'Self-Defence Against Fresh Fruit'
          ^
SyntaxError: invalid syntax
It turns out that <mark>class</mark> is a **keyword**, which is a special word used to specify the structure of a program. Keywords can't be used as variable names.
Here's a complete list of Python's keywords:

You don't have to memorise this list. In most development environments, keywords are displayed in a different colour; if you try to use one as a variable name, you'll know.


# **2.4 The import statement**

In order to use some Python features, you have to **import** them. For example, the following statement imports the <mark>math</mark> module.
`import math`
A **module** is a collection of variables and functions. The math module provides a variable called <mark>pi</mark> that contains the value of the mathematical constant denoted π. We can display its value like this.
`math.pi`
`3.141592653589793`
To use a variable in a module, you have to use the **dot operator** (<mark>.</mark>) between the name of the module and the name of the variable.
The math module also contains functions. For example, <mark>sqrt</mark> computes square roots.
`math.sqrt(25)`
`5.0`
And <mark>pow</mark> raises one number to the power of a second number.
`math.pow(5, 2)`
`25.0`
At this point we've seen two ways to raise a number to a power: we can use the <mark>math.pow</mark> function or the exponentiation operator, <mark>**</mark>. Either one is fine, but the operator is used more often than the function.


# **2.5 Expressions and statements**

So far, we've seen a few kinds of expressions. An expression can be a single value, like an integer, floating-point number, or string. It can also be a collection of values and operators. And it can include variable names and function calls. Here's an expression that includes several of these elements.
`19 + n + round(math.pi) * 2`
`42`
We have also seen a few kind of statements. A **statement** is a unit of code that has an effect, but no value. For example, an assignment statement creates a variable and gives it a value, but the statement itself has no value.
`n = 17`
Similarly, an import statement has an effect - it imports a module so we can use the variables and functions it contains - but it has no visible effect.
`import math`
Computing the value of an expression in called **evaluation**. Running a statement is called **execution**.


# **2.6 The print function**

When you evaluate an expression, the result is displayed.
`n + 1`
`18`
But if you evaluate more than one expression, only the value of the last one is displayed.
`n + 2`
`n + 3`
`20`
To display more than one value, you can use the <mark>print</mark> function.
`print(n + 2)`
`print(n + 3)`
`19`
`20`
It also works with floating-point numbers and strings.
`print('The value of pi is approximately'`
`print(math.pi)`
`The value of pi is approximately`
`3.141592653589793`
You can also use a sequence of expressions separated by commas.
`print('The value of pi is approximately', math.pi)`
`The value of pi is approximately 3.141592653589793`
Notice that the <mark>print</mark> function puts a space between the values.


# **2.7 Arguments**

When you call a function, the expression in parenthesis is called an **argument**. Normally I would explain why, but in this case the technical meaning of  a term has almost nothing to do with the common meaning of the word, so I won't be even try.
Some of the functions we've seen so far take only one argument, like <mark>int</mark>.
`int('101)`
`101`
Some take two, like <mark>math.pow</mark>.
`math.pow(5, 2)`
`25.0`
Some can take additional arguments that are optional. For example, <mark>int</mark> can take a second argument that specifies the base of the number.
`int('101', 2)`
`5`
The sequence of digits <mark>101</mark> in base 2 represents the number 5 in base 10.
<mark>round</mark> also takes an optional second argument, which is the number of decimal places to round off to.
`round(math.pi, 3)`
`3.142`
Some function can take any number of arguments, like <mark>print</mark>.
`print('Any', 'number', 'of', 'arguments')`
`Any number of arguments`
If you call a function and provide too many arguments, that's a <mark>TypeError</mark>.
`float('123.0', 2)`
`TypeError: float expected at most 1 argument, got 2`
If you too few arguments,  that's also a <mark>TypeError</mark>.
`math.pow(2)`
`TypeError: pow expected 2 arguments, got 1`
And if you provide an argument with a type the function can't handle. that's a <mark>TypeError</mark>, too.
`math.sqrt('123')`
`TypeError: must be real number, not str`
This kind of checking can be annoying when you are getting started, but it helps you detect and correct errors.
