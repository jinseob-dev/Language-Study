
In the previous chapter we used several functions provided by Python, like <mark>int</mark> and <mark>float</mark>, and a few provided by the <mark>math</mark> module, like <mark>sqrt</mark> and <mark>pow</mark>. In this chapter, you will learn how to create your own functions and run them. And we'll see how one function can call another. As examples, we'll display lyrics from Monty Python songs. These silly examples demonstrate an important feature - the ability to write your own functions is the foundation of programming.
This chapter also introduces a new statement, the <mark>for</mark> loop. which is use to repeat a computation.


# **3.1 Defining new functions**

A **function definition** specifies the name of a new function and the sequence of statements that run when the function is called. Here's an example:
`def print_lyrics():`
	`print("I'm a lumberjack, and I'm okay.")`
	`print("I sleep all night and I work all day.")`
<mark>def</mark> is a keyword that indicates that this is a function definition. The name of the function is <mark>print_lyrics</mark>. Anything that's a legal variable name is also a legal function name.
The empty parentheses after the name indicate that this function doesn't take any arguments.
The first line of the function definition is called the **header** - the rest is called the **body**. The header has to end with a colon and the body has to be indented. By convention, indentation is always four spaces. The body of this function is two print statements; the body of a function can contain any number of statements of any kind.
Defining a function creates a **function object**, which we can display like this.
`print_lyrics`
`<function __main__.print_lyrics()>`
The output indicates that <mark>print_lyrics</mark> is a function that takes no arguments. <mark>__main__</mark> is the name of the module that contains <mark>print_lyrics</mark>.
Now that we've defined a function, we can call it the same way we call built-in functions.
`print_lyrics()`
`I'm a lumberjack, and I'm okay`
`I sleep all night and I work all day.`
When the function runs, it executes the statements in the body, which display the first two lines of "The Lumberjack Song".


# **3.2 Parameters**

Some of the functions we have seen require arguments; for example, when you call <mark>abs</mark> you pass a number as an argument. Some functions take more than one argument; for example, <mark>math.pow</mark> takes two, the base and the exponent.
Here is a definition for a function that takes an argument.
`def print_twice(string):`
	`print(string)`
	`print(string)`
The variable name in parentheses is a **parameter**. When the function is called, the value of the argument is assigned to the parameter. For example, we can call <mark>print_twice</mark> like this.
`print_twice('Dennis Moore, ')`
`Dennis Moore,`
`Dennis Moore,`
Running this function has the same effect as assigning the argument to the parameter and then executing the body of the function, like this.
`string = 'Dennis Moore, '`
`print(string)`
`print(string)`
`Dennis Moore,`
`Dennis Moore,`
You can also use a variable as an argument.
`line = 'Dennis Moore, '`
`print_lyrics(line)`
`Dennis Moore,`
`Dennis Moore,`
In this example, the value of <mark>line</mark> gets assigned to the parameter <mark>string</mark>.


# **3.3 Calling functions**

Once you have defined a function, you can use it inside another function. To demonstrate, we'll write functions that print the lyrics of "The Spam Song".
`Spam, Spam, Spam, Spam,`
`Spam, Spam, Spam, Spam,`
`Spam, Spam,`
`(Lovely Spam, Wonderful Spam!)`
`Spam, Spam,`
We'll start with the following function, which takes two parameters.
`def repeat(word, n):`
	`print*((word * n)`
We can use this function to print the first line of the song, like this:
`spam = 'Spam, '`
`repeat(spam, 4)`
`Spam, Spam, Spam, Spam,`
To display the first two lines, we can define a new function that uses <mark>repeat</mark>.
`def first_two_lines():`
	`repeat(spam, 4)`
	`repeat(spam, 4)`
And then call it like this.
`first_two_lines()`
`Spam, Spam, Spam, Spam,`
`Spam, Spam, Spam, Spam,`
To display the last three lines, we can define another function, which also uses <mark>repeat</mark>.
`def last_three_lines():`
	`repeat(spam, 2)`
	`print('(Lovely Spam, Wonderful Spam!)')`
	`repeat(spam, 2)`
`last_three_lines()`
`Spam, Spam,`
`(Lovely Spam, Wonderful Spam!)`
`Spam, Spam,`
Finally, we can bring it all together with one function that prints the whole verse.
`def print_verse():`
	`first_two_lines()`
	`last_three_lines()`
`print_verse()`
`Spam, Spam, Spam, Spam,`
`Spam, Spam, Spam, Spam,`
`Spam, Spam,`
`(Lovely Spam, Wonderful Spam!)`
`Spam, Spam,`
When we run <mark>print_verse</mark>, it calls <mark>first_two_lines</mark>, which calls <mark>repeat</mark>, which calls <mark>print</mark>. That's a lot of functions.
Of course we could have done the same thing with fewer functions, but the point of this example is to show how functions can work together.


# **3.4 Repetition**

If we want to display more than one verse, we can use a <mark>for</mark> statement. Here's a simple example.
`for i in range(2):`
	`print(1)`
`0`
`1`
The first line is a header that ends with a colon. The second line is the body, which has to be indented.
The header starts with the keyword <mark>for</mark>, a new variable named <mark>i</mark>, and another keyword, <mark>in</mark>. It uses the <mark>range</mark> function to create a sequence of two values, which are <mark>0</mark> and <mark>1</mark>. In Python, when we start counting, we usually start from <mark>0</mark>.
When the <mark>for</mark> statement runs, it assigns the first value from <mark>range</mark> to <mark>i</mark> and displays it. Then, because that's the last value from <mark>range</mark>, the loop ends.
