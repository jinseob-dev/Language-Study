# **What is a Shell Script?**

Shell scripting lets you bundle long or repetitive terminal commands into a single script - like writing a to-do list your computer can follow automatically.  
Think of it like a recipe. Instead of remembering each cooking step, you write them down and follow the list. Shell scripts work the same way for computer tasks.  
Shell scripts are powerful because they can:
- Automate repetitive tasks
- Combine multiple commands into one action
- Process files in batches 
- Schedule tasks to run automatically
The most common shell on Linux systems is <mark>bash</mark> (Bourne Again Shell). When you create a shell script, you're essentially writing instructions for bash to follow.  
Shell scripts typically have a <mark>.sh</mark> extension, like 
<mark>backup.sh</mark> or <mark>setup.sh</mark>. However, the extension isn't required - Linux identifies scripts by their content, not their name.
Every shell script starts with a special line called a "shebang"  that looks like this:
`#!/bin/bash`
This line tells the system which program should run the script. The <mark>!#</mark> symbols are followed by the path to the bash interpreter.  
Shell scripts can be as simple as two commands or as complex as full applications. They're used everywhere automation tasks.  


# **Writing Your First Script**

Creating your first shell script is straightforward.  
You'll use a text editor to write commands and save them in a file.  
Let's create a simple script that displays information about your system. 
Open your favourite text editors. If you're new to Linux, <mark>nano</mark> is beginner-friendly:
`nano my_firstf_script.sh`
Type the following content:
`#!/bin/bash`
`echo "Welcome to my first script!"`
`echo "Today's date is:"`
`date`
`echo "Current user:"`
`whoami`
`echo "Current directory:"`
`pwd`
Save the file and exit the editor. In nano, press <mark>Ctrl+X</mark>, then <mark>Y</mark>, then <mark>Enter</mark>.  
Let's break down what this script does:  
The first line <mark>#!/bin/bash</mark> tells Linux to use bash to run this script.  
The <mark>echo</mark> command prints text to the screen. You can use it to display messages or information.  
The <mark>date</mark> command shows the current date and time.  
The <mark>whoami</mark> command displays your username.  
The <mark>pwd</mark> command shows your current directory path.  
Each command runs in sequence, just like if you typed them individually in the terminal.  
Shell scripts follow the same syntax as commands you type in the terminal. Any command that works in your shell will work in a script.  
This simple script demonstrates the basic structure that all shell scripts follow: shebang line, followed by commands, one per line.
